能力速览

Claude Code是Anthropic面向软件开发的Agent产品，可以读取代码库，理解错误和需求，修改文件、运行命令与测试，并交付代码差异和说明。用户可从终端、编辑器、桌面或网页安排任务。值得关注的是按任务调用专门Agent，以及把复杂分工写成可检查、可重复运行的编排脚本；云端还能承接持续开发任务。Claude Code提供独立的项目执行入口。可用功能由模型、订阅和入口共同决定，改动需结合测试复核，远程指挥依赖本机在线；原生Windows的命令沙箱、云端配置继承及组织级评审都有明确限制。CC01、CC02、CC07、CC08、CC11、CC12、CC18

3. 突出优势与差异化能力

  1. 专门角色与可重复编排是可辨认的组织方式。 子Agent可按任务匹配被调用；动态编排进一步把分支、循环和中间结果放到脚本及运行时中，主会话接收中间结果的摘要。这是任务组织方式的差异，多Agent的准确性和两种实现的效果需按任务验证。F/J CC07、CC08
  2. 代码会话可连接更长的开发任务过程。 独立工作副本、云会话、远程指挥、PR Auto-fix和Code Projects分别覆盖并行修改、持续执行和项目协调。Claude Code和Codex都有本地、云端及并行能力，主要区别在任务入口、分工方式和交接过程。F/J CC10、CC11、CC12、CC13
  3. 评审按任务入口与执行环境分层。 会话评审、云沙箱Ultrareview与组织Code Review是不同形态，后者还与Cloud Auto-fix分开。各入口分别确认评审粒度、发起方式、访问内容、运行权限和反馈去向。实际发现率需按入口验证。F/J CC14、CC20、CC11

扩展是两者共同能力：项目指令提供背景，Skills提供任务知识，MCP连接系统，Hooks在指定节点执行动作，插件组合扩展。Codex也有Skills、MCP、Hooks及子Agent。F/J CC06、[CX11]、[CX12]

4. 典型应用与能力价值

J：Claude Code的代表应用包括理解陌生项目、修复可复现问题、修改跨文件功能、补充测试及审阅变更。复杂任务可用专门Agent、编排脚本和独立工作副本分担，再把结果交回主会话；云端和PR跟进入口使任务可超出一次聊天。评估开发Agent时，可以同时看模型、可访问的项目内容、执行环境、任务分工方式及可复核的交付记录。与Codex对照时，重点看这些组织与控制方式。

本地、Remote与Cloud 本地会话和Remote依赖执行电脑；Cloud可在本机关闭后继续，但有网络、凭据及资源条件。云会话等待授权、登录等也可能空闲到期；恢复会话后应确认各后台任务的实际状态 F CC11、CC12
云端配置和仓库 本机配置、工具与凭据需按云环境分别确认。Code Projects云线程会读取仓库CLAUDE.md，仓库Skills、.mcp.json和本机设置需另行核对。托管克隆及PR创建面向GitHub。其他仓库可通过本地打包使用，向原GitLab／Bitbucket远端推送需另行完成 F CC11、CC13
模型与渠道 直连、Apps Gateway与第三方云别名映射可能不同，Fable 5.2是否默认由计划与配置决定。CLI、Cloud与Remote的认证条件分别核对，API密钥等方式在当前Remote支持范围之外 F CC04、CC12
计划和组织权限 动态编排、Code Projects、Cloud和组织Code Review各有计划及管理条件。Code Projects公开beta目前面向部分个人付费账号，实际账号权限以入口显示为准 F CC08、CC11、CC13、CC14
评审服务的边界 组织Code Review面向Team／Enterprise及GitHub，由组织启用并单独计用量。服务以只读方式提交审阅发现，构建、运行和合并决定由其他流程处理。应以本次审阅范围解释结果，会话内评审与Cloud Auto-fix各有独立行为 F/O CC14、CC15
深度评审和其他CI入口 Ultrareview为云沙箱研究预览，需显式发起，存在差异规模、账号及提供方限制；这一入口的云沙箱行为需单独核对。组织服务以GitHub为主，Claude也可通过用户自己的GitHub／GitLab CI运行评审 F/O CC20、CC14
区域支持 2026-11-12生效的官方支持地区政策覆盖Claude Code及指定云／转售渠道，中国大陆在支持名单之外。服务支持范围以对应渠道的官方地区清单为准 F CC19
待确认的范围与表现 Code Projects当前公开beta面向个人付费层。具体账号灰度、第三方模型映射、跨平台配置一致性、长任务完成质量及两产品修复率差异仍待核实。非代码文件的适用范围和无人干预任务的稳定性需按实际任务检查 F/U CC04、CC13
